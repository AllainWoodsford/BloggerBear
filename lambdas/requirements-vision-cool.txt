# opencv-python-headless or numpy: the COOL image brings OpenCV's Graviton build of cv2 and the

# then refuse every request as not_cool (vision/build.py's fingerprint check).

# awslambdaric: the Lambda runtime interface client, so the image can run as a container-image
# Lambda (the COOL image is not an AWS Lambda base image). Unused when the image runs elsewhere.
