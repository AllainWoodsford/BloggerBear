# Rubric tracker: OpenCV AI Competition 2026

The final submission closes on **Monday 26 October 2026, 11:45 pm PDT**: 06:45 UTC and 5:45 pm AEDT
on Tuesday 27 October. One row per rubric line (S: the submission package, C: Best Use of COOL,
A: Agentic Vision), one for the owner's own ask (T1), and one per step only the owner can take (O).

**How to update.** Every submission-round PR updates the rows it closes, in the same PR. When an
owner step is done, the owner (or a session asked to) sets its Status and Checked date, with its
evidence committed. Status is `met`, `partly` or `missing`; Needs is any of `code`, `docs`,
`deploy`, `run`, `owner`, or `-` once met. Say is what the assistant may speak, from a closed list
held in code. `scripts/tests/test_hackathon_docs.py` checks this file's format, and the Python CI
runs it on every pull request that touches `docs/hackathon/`, `lambdas/` or `scripts/`.

Demo topics: `rail-sydney-demo` (thresholds of 0, disclosed in the report; every count reports it
apart from the cities).

The package: [the technical report](technical-report.md), [the diagrams](diagrams/README.md),
[the reproduction guide](REPRODUCE.md), [the dependency audit](dependencies.md)
and [the Devpost checklist](devpost-checklist.md), checked
before submitting by `scripts/submission_check.py`; the evaluation's results are indexed in
[RESULTS.md](evidence/RESULTS.md).
